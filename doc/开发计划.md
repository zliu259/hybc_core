# 恒越百川后台管理系统 — 开发计划

## 开发阶段总览

| 阶段 | 内容 | 预计周期 | 里程碑 |
|------|------|---------|--------|
| Phase 0 | 项目初始化与基础设施 | 1周 | 项目骨架可运行 |
| Phase 1 | 认证 + 实体 + 项目管理 | 2-3周 | 基础CRUD完成，可登录操作 |
| Phase 2 | 审批引擎 + AI Slot框架 | 3-4周 | 核心引擎可用 |
| Phase 3 | 对外付款（合同→付款→审计） | 2-3周 | 付款全流程可走通 |
| Phase 4 | 信封报销流程 | 2-3周 | 报销全流程可走通 |
| Phase 5 | 收款流程（合同→发票→收款） | 2周 | 收款全流程可走通 |
| Phase 6 | 资产与仓库管理 | 3-4周 | 设备管理完整可用 |
| Phase 7 | 施工日志 + 进度监控 | 2-3周 | 日志系统完整 |
| Phase 8 | 计算节点部署 + n8n工作流 | 2周 | 自动化运行 |
| Phase 9 | 数据迁移 + 旧数据查询库 | 1周 | 数据就绪 |
| Phase 10 | 小程序开发 | 3-4周 | 小程序上线 |
| Phase 11 | 联调、测试、优化 | 2-3周 | 系统上线 |

**总计预估: 24-34周（约6-8个月）**

## 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| D1性能不足 | 低 | 高 | 历史数据归档R2，热数据保持在D1 |
| AI输出质量不稳定 | 中 | 中 | Prompt迭代+人工覆盖机制+审计追踪 |
| 企微API限制 | 低 | 中 | KV缓存+Queue削峰 |
| 审批引擎复杂度超预期 | 中 | 高 | 先实现核心(顺序签/或签)，再迭代高级功能 |
| 小程序审核延迟 | 中 | 低 | 企微自建应用不走应用市场审核 |
| 计算节点网络不稳定 | 低 | 中 | 多节点冗余+故障转移 |

## 优先级原则

1. **核心流程优先**: 认证→审批→付款→报销 是最高优先级
2. **引擎优先于业务**: 审批引擎和AI Slot是所有业务的基础
3. **Web优先于小程序**: Web端全功能开发完毕后再做小程序
4. **可用优先于完美**: 先实现核心功能，再迭代优化
5. **自动化最后上**: n8n工作流在业务稳定后再配置
