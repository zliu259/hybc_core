# UI 设计文档（V0）

## 设计目标

为恒越百川后台构建清晰、稳重、工程化的管理界面，优先保证：

1. 复杂业务信息可读性
2. 操作路径明确，降低误操作
3. 桌面端与移动端一致可用

## 视觉方向

- 风格关键词：工程、财务、可信、克制
- 主基调：暖灰背景 + 低饱和绿色强调
- 视觉层次：卡片分区、数据块高对比、关键动作强提示

## 色彩系统

- 背景：`#f4f1ea`
- 主卡片：`#fffaf2`
- 主文字：`#2a241d`
- 次文字：`#6e6458`
- 强调色：`#2f6c5f`
- 边框：`#d9ceb9`

语义色建议：

- 成功：`#2f7a53`
- 警告：`#c4872b`
- 危险：`#bd3f3f`
- 信息：`#2d5f9a`

## 字体与排版

- 中文优先：`Noto Sans SC`, `PingFang SC`, sans-serif
- 标题层级：
  - H1: 32-36
  - H2: 24-28
  - H3: 18-20
- 正文：14-16
- 数据密集表格行高：40-44

## 页面框架

1. 顶部导航：系统状态、全局搜索、消息提醒、用户菜单
2. 左侧导航：按业务域分组（项目、财务、施工、资产、审批、系统）
3. 主内容区：
   - 页面标题区（标题、状态、主操作）
   - 过滤区（时间、项目、实体、状态）
   - 数据区（表格/卡片/图表）

## 核心页面原型策略

### 1) 仪表盘

- 上：核心 KPI 卡片（应付、应收、报销、审批待办）
- 中：趋势图（周/月）
- 下：风险与异常列表（AI 结果+业务规则）

### 2) 列表页（项目/合同/申请单）

- 顶部过滤条件固定
- 操作列固定在右侧
- 详情采用右侧抽屉，减少页面跳转

### 3) 详情页（审批与财务单据）

- 左侧主体信息
- 右侧审批轨迹与风险提示
- 底部固定动作条（通过/拒绝/退回/转签）

## 交互规范

- 所有危险操作必须二次确认
- 金额相关输入展示格式化与大写预览
- 审批动作统一弹窗模板，强制填写意见
- 异常与AI建议分开展示，避免误解为系统强制结论

## 响应式策略

- >=1200: 三栏或双栏
- 768-1199: 双栏压缩
- <768: 单栏堆叠，操作按钮合并为底部浮动栏

## 组件优先级

P0:

- 通用表格容器
- 高级筛选条
- 金额展示组件
- 审批轨迹组件

P1:

- 风险提示组件
- AI建议卡片组件
- 项目状态时间线

## 可用性与无障碍

- 文字对比度满足 WCAG AA
- 关键按钮尺寸 >= 36px
- 表格支持键盘导航
- 状态信息不只靠颜色区分

## 与代码实现映射

- `packages/web/src/views/*`：页面容器
- `packages/web/src/components/*`：复用组件
- `packages/web/src/composables/*`：筛选、分页、权限逻辑
- `packages/web/src/api/*`：后端接口封装

## V0 验收标准

1. 仪表盘、列表页、详情页具备统一布局
2. 关键业务颜色与状态语义一致
3. 移动端可完成审批基础动作
4. 与后端 `/api/v1` 路由风格一致
