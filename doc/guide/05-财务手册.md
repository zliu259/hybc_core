# HYBC Core 培训手册 05：财务

## 1. 岗位目标
- 保证每一笔业务“有依据、可追溯、可对账”。

## 2. 重点功能
- 报销预审、查重、批次审核。
- 付款资料审核与流转跟踪。
- 收款与发票状态管理。
- 财务异常项管理与闭环。

## 3. 标准财务流程
1. 先做资料完整性检查。
2. 再做金额与合同一致性检查。
3. 通过后进入审批流转。
4. 完成后进行对账与归档。

## 4. 风险控制流程
1. 发现异常先暂停流转。
2. 标记异常类型并通知责任岗位。
3. 补齐材料后复核。
4. 复核通过再恢复流程。

## 5. 常见问题
- 金额不一致：优先核对合同、申请单、附件三处信息。
- 反复退回：统一退回原因，避免多轮沟通。
- 账实不符：先锁定时间范围，再逐单核对。

## 6. 培训考核建议
- 完成一次“报销审核 + 付款审核 + 收款核对”的完整练习。

## 油卡处理工作台

财务/办公室进入“车辆油卡 / 油卡处理工作台”，按待处理队列处理申请。处理前查看风险摘要、规则命中、车辆、油卡和照片信息；可选择通过并回写余额、退回补充或拒绝。处理结果会通知申请人并进入审计记录。
