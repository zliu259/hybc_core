# HYBC Core 培训手册 04：现场操作员

## 1. 岗位目标
- 快速、准确地完成一线数据采集与执行反馈。

## 2. 你最常用的功能
- 工作台待办查看。
- 日志填报与现场情况上报。
- 设备扫码与状态确认。
- 报销与附件提交。

## 3. 每日操作流程
1. 上班后先看待办和提醒。
2. 作业过程中实时记录，不要等到下班补填。
3. 发现异常立即上报，并附照片或说明。
4. 下班前检查当天待办是否清零。

## 4. 提高效率的小技巧
- 使用统一描述模板，避免来回补充说明。
- 附件一次拍清楚，减少重复上传。
- 不确定怎么填时，先选最接近项并备注说明。

## 5. 常见问题
- 提交按钮灰色：通常是必填信息未完成。
- 一直提示失败：先确认网络，再重新进入页面。
- 找不到任务：确认当前选择的是正确项目。

## 6. 培训考核建议
- 在 15-20 分钟内完成一次“待办处理 + 日志上报 + 异常提交”演练。

## 油卡额度申请与补充

现场操作员可在小程序“油卡额度申请”中选择车辆、本人绑定油卡、填写额度和里程并上传现场照片。若状态变为“待补充资料”，按页面提示补充照片或修正里程后重新提交。
