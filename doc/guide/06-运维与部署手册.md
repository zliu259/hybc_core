# HYBC Core 培训手册 06：系统运行保障手册

## 1. 适用对象
- 系统管理员、超级管理员、培训负责人。

## 2. 目标
- 保证系统“持续可用、问题可发现、异常可恢复”。

## 3. 每日运行检查
1. 查看系统运行总览，确认是否有红色告警。
2. 查看审批流转是否存在异常积压。
3. 查看财务流转是否存在超时或异常退回。
4. 查看现场数据上报是否连续。

## 4. 异常分级与处理
- 一级（影响广）：核心流程不可用，立即升级处理。
- 二级（影响中）：部分岗位无法操作，限时修复。
- 三级（影响小）：体验问题或偶发错误，纳入排期。

## 5. 应急处理流程
1. 先止损：暂停高风险流转。
2. 快速通报：明确影响范围与临时方案。
3. 定位根因：区分配置问题、流程问题、数据问题。
4. 恢复后复盘：沉淀问题与防复发措施。

## 6. 培训考核建议
- 每月一次“故障演练日”，覆盖审批异常、财务异常、现场异常三类场景。
