# HYBC Core 培训手册 02：经理

## 1. 岗位目标
- 对项目结果负责，确保“进度、成本、审批”三条线同步推进。

## 2. 重点功能
- 项目管理：项目建立、阶段推进、关键里程碑跟踪。
- 审批中心：处理跨部门待办，跟踪关键事项。
- 财务协同：关注付款、收款、报销的流转效率。

## 3. 每日工作流程
1. 早会前查看工作台和项目看板。
2. 优先处理紧急审批和阻塞事项。
3. 跟进当日关键财务事项（大额、超期、退回项）。
4. 下班前复核当天状态变化与风险项。

## 4. 周度管理流程
1. 回顾本周项目进度达成情况。
2. 汇总审批时效与退回原因。
3. 与现场和财务对齐下周重点事项。

## 5. 常见问题处理
- 审批长期卡住：先定位卡在哪个节点，再协调对应岗位。
- 项目进度与现场反馈不一致：优先核对日志和勘查记录。
- 财务数据偏差：先做单据对齐，再判断是否需要补录。

## 6. 培训考核建议
- 完成一次“项目推进会模拟”：审批清理、风险复盘、下周计划输出。
