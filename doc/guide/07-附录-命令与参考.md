# HYBC Core 培训手册 07：附录（术语、流程、常见问题）

## 1. 术语速查
- 待办：当前需要你处理的事项。
- 退回：资料不足或信息不清，返回补充。
- 转签：将事项转给更合适的处理人。
- 驳回：事项不通过，流程终止。
- 归档：流程完成并保留记录，供后续审计与复盘。

## 2. 通用流程模板（培训统一话术）
1. 查看待办。
2. 打开详情。
3. 完成检查（信息、金额、附件、说明）。
4. 做处理动作（通过/退回/转签/驳回）。
5. 复核状态是否更新。

## 3. 常见场景处理
- 看不到功能：先确认岗位权限，再联系管理员。
- 提交失败：先补齐必填信息与附件。
- 数据对不上：先按时间和项目过滤后再核对。
- 审批卡住：确认卡在哪个节点，再找对应岗位。

## 4. 培训安排建议
- 新员工：入职当天完成岗位功能演练。
- 岗位复训：每两周一次，聚焦常见错误。
- 联动演练：每月一次，覆盖现场、审批、财务全链路。

## 5. 培训验收建议
- 能独立完成本岗位 1 次标准流程。
- 能说清楚本岗位与上下游岗位的协作关系。
- 能独立处理 2 个常见异常场景。
