# HYBC Core 培训手册 01：超级管理员

## 1. 岗位目标
- 确保系统稳定可用、审批规则正确、风险可控。

## 2. 你负责的功能模块
- 审批规则与流程模板。
- 金额阈值与分级审批策略。
- AI 任务策略与异常任务处理。
- 系统运行状态与告警处理。

## 3. 每日巡检流程
1. 先看运行总览，确认是否有异常积压。
2. 查看审批中心异常流程（长时间未流转、反复退回）。
3. 查看财务相关异常（高金额、高风险、资料不完整）。
4. 记录当天处理动作，便于复盘。

## 4. 规则调整流程（标准版）
1. 明确业务目标和影响范围。
2. 在测试环境演练一遍完整流程。
3. 安排小范围试运行并收集反馈。
4. 正式发布后观察关键指标至少一个工作日。

## 5. 高风险事项处理
- 出现审批大面积卡顿：先启用应急处理规则，再定位根因。
- 出现金额风险告警：先冻结流程，再要求补充材料。
- 出现权限误配：先收敛权限，再通知相关岗位重新验证。

## 6. 培训考核建议
- 在 20 分钟内完成一次“规则调整 -> 流程验证 -> 结果复核”演练。
