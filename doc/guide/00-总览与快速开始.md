# HYBC Core 培训手册 00：总览与快速开始

## 1. 这套系统是做什么的
- 帮助团队把“项目现场、审批流、财务流、资产流”放到同一套平台协同。
- 支持管理端与移动端协同，保证“现场发生 -> 系统记录 -> 管理决策”闭环。

## 2. 你会用到的核心功能
- 项目与现场：项目建立、进度跟踪、现场协同。
- 审批中心：待办审批、退回补充、历史追踪。
- 财务中心：报销、付款、收款、发票与统计。
- 施工日志：操作员日志、管理日志、现场勘查。
- 资产仓库：设备台账、出入库、盘点、异常预警。

## 3. 角色分工（培训版）
- 超级管理员：管规则、管配置、管风险。
- 经理：管项目推进、跨部门协调、关键审批。
- 现场管理员：管现场执行与现场数据质量。
- 现场操作员：做一线填报、扫码、上报。
- 财务：做报销、付款、收款、发票与对账。

## 4. 新员工 30 分钟上手流程
1. 登录系统后先进入个人工作台，查看今日待办。
2. 按自己岗位进入对应功能区，完成 1 次“查看 + 新增 + 提交”动作。
3. 到审批中心完成 1 次待办处理，理解流程状态变化。
4. 回到工作台确认结果回写（待办数、状态、提醒是否变化）。

## 5. 使用原则
- 先做标准流程，再做特殊处理。
- 任何“无法提交”的情况，先检查必填项与附件。
- 任何“数据异常”先记录，再交由对应岗位处理。
