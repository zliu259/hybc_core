# HYBC Core 培训手册 03：现场管理员

## 1. 岗位目标
- 保障现场执行“有记录、有闭环、可追溯”。

## 2. 重点功能
- 现场任务分配与进度反馈。
- 施工日志与现场勘查管理。
- 资产出入库、盘点与调度协同。
- 现场相关审批处理。

## 3. 每日现场管理流程
1. 开工前：确认今日任务、人员、设备状态。
2. 作业中：组织填报日志，及时上报异常。
3. 收工前：复核数据完整性，补齐附件与说明。
4. 当日结尾：处理待办审批，确保事项不过夜。

## 4. 现场异常处理流程
1. 发现异常先记录事实（时间、地点、影响）。
2. 快速分类：安全类、设备类、进度类、财务类。
3. 提交对应处理单并通知相关岗位。
4. 跟踪到关闭，避免“提交后无人处理”。

## 5. 管理重点
- 把数据质量放在第一位：不完整数据会导致审批和结算卡顿。
- 现场口头信息必须沉淀到系统，避免后续扯皮。

## 6. 培训考核建议
- 完成一次“现场异常从上报到关闭”的全流程演练。
